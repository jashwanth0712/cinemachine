CineMachine - Storytelling Mode for Kids
=========================================

Concept: Voice agent guides a child through creating a movie with their toys
using the laptop camera. Interactive conversation + camera + scene recording.

Session Flow:
  1. Kid clicks "Start Story" -> connect Gemini Live, start camera + mic
  2. Agent greets kid, asks about the story
  3. Kid shows characters one by one -> agent calls register_character (snapshot)
  4. Kid says "action" -> agent calls start_scene_recording (MediaRecorder)
  5. Kid says "cut" -> agent calls stop_scene_recording (save blob)
  6. Repeat scenes, allow retakes
  7. Kid says "let's export" -> stitch blobs, download .webm

Tool Calls:
  - register_character { name } -> snapshot + store thumbnail
  - start_scene_recording { scene_number, description } -> MediaRecorder start
  - stop_scene_recording { scene_number } -> MediaRecorder stop, save blob
  - export_movie {} -> concatenate blobs, trigger download
